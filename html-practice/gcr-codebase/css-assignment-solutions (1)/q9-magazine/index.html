The Daily Column

Newspapers have used multi-column layouts for centuries, long before the web existed, because dense text is easier to read in narrow measures than in a single wide block stretching across a page.

Modern CSS makes this trivial to reproduce with the column-count property, letting text flow automatically from one column into the next without any manual breaking of paragraphs.

Combined with column-span, a heading or image can break out of the column flow entirely, spanning the full width of the container to anchor the layout the way a masthead or feature photo would in print.

Floating an image within the text lets copy wrap naturally around it, a technique that predates CSS itself but still reads as clean and intentional today.

Justified text, careful column gaps, and a restrained color palette keep the whole thing feeling like something you would actually want to sit down and read.
